# io.pasx.webui.orderexecution.fat
Automated FAT tests for PAS-X WebUI Order Execution

## Development Guidelines

In order to keep everything and everyone on the same page please refer to [CONTRIBUTE.md](./CONTRIBUTE.md) for development.

## Development Setup

You will need [Node.js](http://nodejs.org) with the version defined in `.nvmrc` and [npm](https://www.npmjs.com/get-npm).

```
> install the dependencies of the project
$ npm install
```

```
> runs format, lint and cucumber tests
$ npm run before:commit
```

```
> CLI tool to help following commit conventions
$ npm run commit
```

```
> run eslint with --fix option
$ npm run lint
```

```
> format code using prettier
$ npm run format
```

```
> install dependencies required to run e2e tests
$ npm run install:e2e
```

```
> run automated tests
$ npm run test
```
